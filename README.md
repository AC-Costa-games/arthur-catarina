# Jogos do Arthur e da Catarina

Jogos pessoais feitos para as crianças. Todos rodam no navegador do celular.

**Página com todos os jogos:** https://ac-costa-games.github.io/arthur-catarina/

| Jogo | Jogar no navegador | App Android |
|---|---|---|
| [Arthur Lorenzo Fly](arthur-lorenzo-fly/) | https://ac-costa-games.github.io/arthur-catarina/arthur-lorenzo-fly/ | APK em [Releases](https://github.com/AC-Costa-games/arthur-catarina/releases) |

## Como o repositório está organizado

- `index.html`: página inicial com a lista de jogos.
- Uma pasta por jogo (por exemplo `arthur-lorenzo-fly/`), com o próprio `README.md`.
- `.github/workflows/`: uma automação por jogo que tem app Android, para gerar o APK.

## Adicionar um jogo novo

1. Crie uma pasta com o nome do jogo e coloque nela o `index.html` do jogo.
2. Adicione um cartão para ele no `index.html` da raiz.
